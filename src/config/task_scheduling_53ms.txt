TAREA | PERIODO | PRIORIDAD | ID CAN | DESCRIPCION
T1_VCU_Traction | 53ms | ALTA (10) | 0x100 | Lectura SOC + Torque. Critica para ADAS L23. Si falla >150ms -> SAFE MODE

# Justificacion 53ms:

# Evita colision y cumple requerimiento de seguridad ISO 26262.

Failsafe: Si SOC <20% o latencia CAN >150ms => Safe Mode = Torque 0, Freno 50%
